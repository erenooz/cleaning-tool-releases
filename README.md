# ImpactSense Cleaning Tool: releases

This repository holds only the built releases of the ImpactSense Cleaning Tool
(Windows and macOS). It contains no source code and no keys.

**Download:** open [Releases](../../releases/latest) and pick the zip for your computer:

| Computer | File |
|---|---|
| Windows | `...-win64.zip` |
| Mac with an Apple M chip | `...-macos_arm64.zip` |
| Mac with an Intel chip | `...-macos_x86_64.zip` |

After the first install, the app checks this page for updates and installs
them itself. Every download is verified against the SHA-256 checksum in
`latest.json` before it is installed.
